# Expense tracker

Replace the Vite starter with a simple expense tracker. Users can add a title, amount and category, filter the list and delete entries. The displayed total and count follow the selected category. Validation rejects blank titles, invalid or nonpositive amounts, amounts above 100000 and fractions smaller than a paise.

App owns state, with separate form, list, item and filter components. The change also adds the prompt library, project guide, Vitest tests and Cypress specs.
